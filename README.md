Mini CRM Distribution Service

Сервис для распределения лидов между операторами по разным каналам 
на Python с использованием FastAPI и SQLAlchemy.

Функционал:
Хранение операторов и их нагрузка
Учёт лидов и каналов поступления заявок

Особенности:
Разделение обязанностей операторов и источников (ботов)
Модель весов OperatorSourceWeight для настройки распределения

Запуск:
pip install -r requirements.txt
uvicorn main:app --reload

API-документация через Swagger UI:
http://127.0.0.1:8000/docs

Маршруты API:
POST /create_operator/ — Создание нового оператора
GET /list_operators/ — Получение списка операторов
PUT /update_operator/{operator_id} — Обновление данных оператора
POST /register_contact/ — Регистрация нового обращения
GET /view_contacts/ — Просмотр всех зарегистрированных обращений

Модель данных:
Операторы: обработка обращений
Лиды: конечные клиенты
Источники: каналы поступления заявок (боты)
Связи между ними — в models.py

Спроектирована модель данных и API-каркас.
